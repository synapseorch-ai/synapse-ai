# Knowledge's optional parsers (A2, D162). Without them Knowledge still reads
# every format with its own readers; with them, PDFs go through Docling's layout
# model and TableFormer (tables, reading order, running headers), and HEIC
# photos can be read by OCR.
#
#   pip install 'synapse-orch-ai[knowledge]'             (a packaged install)
#   pip install -r backend/requirements-knowledge.txt    (from source)
#
# Then fetch Docling's models once; nothing is downloaded at run time:
#
#   docling-tools models download layout tableformer -o "$DOCLING_ARTIFACTS_PATH"
#
# (DOCLING_ARTIFACTS_PATH, else <state dir>/models/docling). Docling is used only
# when it imports and those models are there; otherwise the basic PDF reader runs.
#
# System packages, Debian/Ubuntu: Docling's OpenCV needs `libxcb1 libgl1
# libglib2.0-0`. LibreOffice (`libreoffice-writer-nogui libreoffice-calc-nogui
# libreoffice-impress-nogui`) reads .doc/.xls/.ppt; it is found as `soffice` on
# PATH or at SYNAPSE_SOFFICE.
#
# torch is the CPU build in requirements-knowledge.lock (PyTorch's CPU index):
# Knowledge runs no model on a GPU. Installing the lock therefore needs that index:
#   pip install -r requirements-knowledge.lock --extra-index-url https://download.pytorch.org/whl/cpu
#   uv pip install --no-config -r requirements-knowledge.lock --torch-backend cpu
# (--no-config: the repo's pyproject.toml [tool.uv] holds the root uv.lock to these
# locks, and uv finds it from here; it is not for a pip install.)
# Measured (A2, 16 §8, python:3.12-slim): the image with this extra, its models and
# LibreOffice is 2.97 GB (models 0.67 GB); a 48-page PDF parses at 2.2 s a page on
# 2 vCPUs, peaking at 1.8 GB in 4-page batches.
# pillow-heif bundles libheif and libde265 (LGPL-3.0), dynamically linked.
#
# Upper bounds are mandatory here too — see the header of requirements.txt.
docling-slim[format-pdf,models-local,convert-core,cli]>=2.142,<3
docling-core>=2.104,<3
# TableFormer imports cv2; docling-ibm-models leaves OpenCV to an extra, which full
# `docling` reaches only through RapidOCR (left out here). Headless: no GUI libraries.
opencv-python-headless>=4.6,<5
torch>=2.2.2,<3
torchvision>=0.17,<1
pillow-heif>=0.18,<2
