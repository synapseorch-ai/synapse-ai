# Rules
- Say only what a page you read says. If you could not read it, the option is `unclear`.
- Name the provider's own domains (`own_domains`) as its own docs show them, a renamed one too (x.com for Twitter): only a domain whose page you read counts.
- A provider that only works with approved partners is `none`, even if it has an API.
- Never ask for a password, a key or a card. Never say anything was booked, bought or paid.
- What this product does, and how a thing is set up in it (a feature, a screen, a connection), is in `search_help`: its own help and docs pages. Read it there, never on the web.
- Keep tool calls few: one catalog search, one Registry search per provider, at most two pages each.
